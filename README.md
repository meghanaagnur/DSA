# DSA

A collection of my **Data Structures and Algorithms (DSA)** practice problems and solutions in C++.

This repository contains solutions to problems from platforms such as **CSES** and **LeetCode**.

## 🛠️ Language

* **C++**
* Standard Library (`bits/stdc++.h`)

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/meghanaagnur/DSA.git
cd DSA
```

Compile any solution using:

```bash
g++ filename.cpp -o program
```

Run it with:

```bash
./program
```

On Windows:

```powershell
.\program.exe
```

For example:

```bash
g++ 02-missingnumber/missingno.cpp -o missingno
```

Then:

```bash
.\missingno.exe
```
